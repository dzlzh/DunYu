# 遁鱼首版使用与验证

当前为需要 Windows 验证的开发版本。支持 Windows 10/11 x64 的普通桌面窗口；不保证可操作系统窗口、权限更高的窗口或特殊分层绘制窗口。

## 构建与运行

Windows 安装 Rust 1.96 和 Visual Studio C++ Build Tools（含 Windows SDK），运行：

```powershell
cargo test --locked --all-targets
cargo build --locked --release
.\target\release\dunyu.exe
```

首次启动显示设置，以后驻留托盘。双击托盘图标打开设置；再次启动程序也会打开已有实例。关闭设置窗口不退出。托盘菜单提供单独恢复、全部恢复和退出。

CI 在 Windows 与 Linux 上运行测试，Windows 构建任务提供便携 ZIP 和 SHA256 校验和；上传 artifact 不代表桌面人工验收已经通过。项目已包含 Cargo.lock，使用 --locked 构建以固定依赖。当前 Windows x64 GNU Release 已交叉编译成功，11 项 Linux 核心测试通过；Windows 集成测试仅完成编译，仍需实机运行。

## 召唤

点击“新建规则”，填写启动路径、快捷键及实际进程完整路径，保存。支持可执行程序以及快捷方式；快捷方式必须填写目标应用实际进程路径，不能用 `.lnk` 路径匹配进程。

“捕获窗口信息”隐藏设置窗口，三秒后读取前台窗口；这期间切换到需要控制的程序。窗口类名和标题是可选条件，标题采用包含匹配；捕获后可以清空会动态变化的标题。

同一规则只控制一个窗口。目标在前台时隐藏，否则恢复并激活。找不到窗口时启动程序；十秒内未匹配到窗口会提示，不会终止目标程序。

## 默认快捷键

| 操作 | 快捷键 |
|---|---|
| 绑定当前窗口至槽位 1～4 | Ctrl+Alt+Shift+1～4 |
| 显示／隐藏槽位 1～4 | Ctrl+Alt+1～4 |
| 降低／提高不透明度 | Ctrl+Alt+Left / Right |
| 当前窗口恢复 100% | Ctrl+Alt+0 |
| 恢复所有受控状态 | Ctrl+Alt+Backspace |

绑定只在当前会话有效。绑定页可以调整快捷键和重新捕获目标。隐现页选择窗口后使用滑块调整不透明度。快捷键字段支持 Ctrl、Alt、Shift、Win 加字母、数字、F1～F11、Left、Right、Space 或 Backspace。

## 配置与恢复

配置在可执行文件旁的 `data/config.json`，恢复记录在 `data/recovery.json`。请将便携版解压到可写目录。正常退出会发送窗口恢复请求；目标程序无响应时，恢复可能延后。强制结束后重新启动可尝试恢复仍存活且身份相符的窗口。

不要在受控窗口仍隐藏时删除、移动或修改恢复记录。记录损坏时会保留原文件并禁止新的窗口修改。恢复只针对遁鱼修改的属性，不操作已复用的窗口句柄。自启动默认关闭，使用当前用户启动项，不自动提升权限。

## 人工验收清单

- Windows 10 22H2、Windows 11；普通窗口、最大化、最小化、隐藏与恢复。
- 同一应用多个窗口；窗口关闭后重新创建；中文／空格路径、快捷方式。
- 与其他程序冲突的快捷键；保存失败后旧快捷键继续生效。
- 原有分层／色键透明窗口；不支持的特殊渲染窗口应报错而非强改。
- 操作后正常退出；任务管理器结束遁鱼后重新启动；只读数据目录、损坏配置。
- 托盘重建、重复启动、开机启动；多显示器与缩放。
- 记录空闲 CPU、工作集和发布包大小；无启动或捕获任务时不持续扫描窗口。

通知转发、工作区、安装包及配置迁移不在此首版中。
