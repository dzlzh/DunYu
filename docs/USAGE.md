# 遁鱼首版使用与验证

当前为需要 Windows 验证的开发版本。支持 Windows 10/11 x64 的普通桌面窗口；不保证可操作系统窗口、权限更高的窗口或特殊分层绘制窗口。

## 构建与运行

Windows 安装 Rust 1.96 和 Visual Studio C++ Build Tools（含 Windows SDK），运行：

```powershell
cargo test --locked --all-targets
cargo build --locked --release
.\target\release\dunyu.exe
```

首次启动显示设置，以后驻留托盘。双击托盘图标打开设置；再次启动程序也会打开已有实例。关闭设置窗口不退出。托盘菜单提供单独恢复、全部恢复和退出。

“设置 → 启动与后台运行”中的“隐藏托盘图标”默认关闭，保存成功后立即生效并保留到下次运行。启用后，有配置时启动仅在后台运行，再次运行程序才打开已有实例的配置界面；首次使用和配置错误仍会显示界面。打开配置不会恢复托盘图标，关闭配置后快捷键和休憩提醒继续工作；Explorer 重启后也保持隐藏。取消勾选并保存可恢复托盘，再从托盘菜单退出并恢复受控窗口。

设置窗口使用顶部页签切换召唤、绑定、隐现、休憩、传讯和设置。支持调整窗口大小及显示器 DPI 缩放；内容超出窗口时可滚动，底部保存按钮保持可见。Tab 导航会将当前输入框滚动到可见区域。

各页仍需手动保存。切换页面或关闭到托盘会保留输入；切换规则、新建规则将覆盖未保存修改时，会提示保存、放弃或取消。删除规则前会确认。保存成功后保持当前规则选中，失败时保留输入并在底部显示原因。

CI 在 Windows 与 Linux 上运行测试，Windows 构建任务提供便携 ZIP 和 SHA256 校验和；上传 artifact 不代表桌面人工验收已经通过。项目已包含 Cargo.lock，使用 --locked 构建以固定依赖。当前 Windows x64 GNU Release 已交叉编译成功，26 项 Linux 核心测试通过；Windows 集成测试仅完成编译，仍需实机运行。

## 界面与视觉验收

界面采用深灰背景、暗色分组面板和蓝色主操作；输入区域、导航和规则列表提供选中及键盘焦点反馈。绑定槽位默认两列，窗口宽度小于 840 逻辑像素时切为单列。系统高对比模式使用系统颜色。配置和操作流程保持兼容。

Windows CI 会运行原生界面测试并上传 `DunYu-ui-preview` 图片产物。图片来自真实 HWND 的窗口绘制，不包含其他应用的桌面内容。也可在 Windows 本地运行：

```powershell
$env:DUNYU_UI_SCREENSHOTS = '1'
cargo test --locked editor_drafts_selection_layout_and_target_state -- --test-threads=1
```

BMP 截图写入 `target/ui-preview`，CI 另将其转换为 PNG。 按钮文字回归检查覆盖 14、20、28 逻辑像素字号及 100%、125%、150%、200% DPI；启用截图时额外输出 `large-text-0.bmp` 至 `large-text-5.bmp`。检查六页、空状态、选中行、聚焦与悬停、禁用状态、高级项展开，以及 100%～200% 缩放和跨屏往返。截图测试成功不替代 Windows 10/11 实机鼠标、键盘与高对比验收。Linux 交叉构建只能验证编译，不能验证 Windows 视觉效果。

## 召唤

点击“新建”，填写启动路径及实际进程完整路径，点击快捷键框后直接按下组合键，再保存。支持可执行程序以及快捷方式；快捷方式必须填写目标应用实际进程路径，不能用 `.lnk` 路径匹配进程。

也可以点击“浏览…”选择 `.exe` 或 `.lnk`。选择可执行程序时，只自动补全尚未填写的匹配进程路径。启动参数、工作目录、进程路径、类名、标题与最小化选项位于“高级选项”内；已有高级条件的规则会自动展开。选择快捷方式后会展开高级项并提示核对实际进程路径。

“捕获窗口”隐藏设置窗口，三秒后读取前台窗口；这期间切换到需要控制的程序。窗口类名和标题是可选条件，标题采用包含匹配；捕获后可以清空会动态变化的标题。

同一规则只控制一个窗口。目标在前台时隐藏，否则恢复并激活。找不到窗口时启动程序；十秒内未匹配到窗口会提示，不会终止目标程序。

## 默认快捷键

| 操作 | 快捷键 |
|---|---|
| 绑定当前窗口至槽位 1～4 | Ctrl+Alt+Shift+1～4 |
| 显示／隐藏槽位 1～4 | Ctrl+Alt+1～4 |
| 降低／提高不透明度 | Ctrl+Alt+Left / Right |
| 当前窗口恢复 100% | Ctrl+Alt+0 |
| 恢复所有受控状态 | Ctrl+Alt+Backspace |

绑定只在当前会话有效。绑定页可以调整快捷键和重新捕获目标。隐现页选择窗口后使用滑块调整不透明度。快捷键字段支持 Ctrl、Alt、Shift、Win 加字母、数字、F1～F11、Left、Right、Space 或 Backspace。

隐现页显示目标的实际不透明度百分比，捕获、快捷键调整和恢复后会同步刷新。未选择有效目标或窗口不支持调整时，滑块和当前窗口恢复按钮不可用。捕获其他窗口、恢复操作或目标失效会取消尚未应用的滑块更新。

增减不透明度支持长按连续调整：按住 Ctrl+Alt，再按住 Left 或 Right；松开即停止。单按调整一次，长按的开始延迟和重复速度遵循 Windows 键盘设置，每次按设置页的步长调整。想更细腻可将步长设为 1～2；范围始终为 10%～100%。召唤、绑定、显示／隐藏和恢复操作仍只在每次按下时触发一次。

所有快捷键框均直接捕获按键，无需手填文字：点击框后按住修饰键，再按主键。仅按修饰键时显示待补全提示（例如 `Win+…`），松开或离开字段后恢复已录入的值；无修饰键、F12 或不支持的按键保留原值。Tab／Shift+Tab 切换字段，Enter 或 Esc 离开字段；点击相应保存按钮后生效。录入时遁鱼自身已有的快捷键不会执行原操作，离开字段后正常响应。前台快捷键框使用临时键盘钩子识别左右 Win 键，离开录入后释放。能录入的组合仍需系统允许注册；系统保留组合或其他程序占用时，保存会提示具体组合并保留旧配置。

## 配置与恢复

配置在可执行文件旁的 `data/config.json`，恢复记录在 `data/recovery.json`。请将便携版解压到可写目录。正常退出会发送窗口恢复请求；目标程序无响应时，恢复可能延后。强制结束后重新启动可尝试恢复仍存活且身份相符的窗口。

不要在受控窗口仍隐藏时删除、移动或修改恢复记录。记录损坏时会保留原文件并禁止新的窗口修改。恢复只针对遁鱼修改的属性，不操作已复用的窗口句柄。自启动默认关闭，使用当前用户启动项，不自动提升权限。

## 暗色界面验证

界面默认暗色，小鱼图标用于软件文件、窗口、任务栏、托盘及页头；导航图标随 DPI 缩放。系统高对比模式使用系统颜色。

验证滚动残影时，将窗口缩小到最小尺寸，打开高级选项，连续上下滚动及拖动滚动条，再调整窗口大小；六个页面及规则列表都应保持文字和边框完整。分别在 100%、125%、150%、200% 缩放重复。须观察实际滚动后的画面，不能仅用强制重绘截图代替。

图标素材由内置 imagegen 生成，源图为 `resources/fish.png`，多尺寸资源为 `resources/dunyu.ico`。本版采用深青底的朱砂环形锦鲤；设计源图见 [环形图标](design/app-icon-loop.png)，视觉说明见 [art-style.md](../resources/art-style.md)。

交互式 Windows 桌面可设置 `DUNYU_UI_SCROLL_CHECK=1`，运行 `cargo test editor_drafts_selection_layout_and_target_state -- --test-threads=1`，比较实际滚动画面与完整重绘画面。测试期间保持窗口可见、不受遮挡。差异图片保存在 `target/ui-preview/scroll-*.bmp`。

## 休憩

小憩和舒展分别启用、独立设置间隔和时长，默认关闭。小憩默认每20分钟休息20秒，舒展默认每60分钟休息5分钟。等待小憩时，舒展计时继续；休息期间两种工作计时暂停。舒展到点会优先于尚未开始的小憩；同时到期时合并为一次舒展，避免连续弹出。结束小憩不会重置舒展的计时。旧配置的“工作间隔×舒展轮次”自动换算成舒展间隔，保存后使用新的分钟数。

- 工作间隔的最后30秒在当前屏幕顶部居中预告，不抢键盘焦点。小憩和舒展分别设置“到点自动开始”；开启后到点自动休息，关闭则只提醒，等待点击“现在休息”。例如关闭小憩自动开始、开启舒展自动开始，即可只提醒小憩而自动进入舒展。两个开关默认开启，休憩功能本身仍默认关闭。
- 小憩“稍后”为2分钟，舒展为5分钟，可重复延后，延后到期前再次预告30秒；只有“跳过本轮”或“结束休息”会提前进入下一轮。Esc和右上角“×”只隐藏当前提醒，不改变计时与轮次；自动模式仍按计划开始休息，只提醒模式保持等待且不反复弹出。关闭休息画面后倒计时继续，关闭预览不影响计划。
- 全屏模式覆盖全部显示器；点击任意屏幕的“结束休息”按钮会结束整次休息；Esc或“×”只关闭全部休息画面，计时继续。
- “现在休息”立即开始下一次计划中的休息。“预览提醒”按已保存的显示模式演示5秒，不推进轮次，停用状态也可预览。
- 托盘或页面可以暂停、恢复；恢复时重新计算完整工作间隔。重启重新计时，不补发未运行期间的提醒。
- 默认连续5分钟无键鼠输入视为自然休息，返回后重置工作间隔和轮次。锁屏、睡眠期间工作计时暂停；短暂离开保留进度。已经开始的休息可在离开期间完成；未完成时返回后重新预告30秒；按该类休息的自动开始开关决定继续休息或等待点击。
- 默认在系统报告全屏、演示或暂不适合通知时暂缓提醒，解除后显示完整30秒预告，只处理一次休息。自动恢复不会解除未到期的手动暂停。

数值范围：间隔1～1440分钟，小憩1～3600秒，舒展1～120分钟，舒展间隔1～1440分钟。设置保存在原配置文件的 `rest` 字段；旧配置缺失该字段时自动使用关闭状态。保存失败保留原设置，保存其他页面不重置休憩计时。

核心调度测试可在 Linux 运行。Windows 集成测试包含六页截图、卡片预览和全屏窗口数量／位置检查；真实多屏、显示器插拔、锁屏、睡眠恢复及不抢焦点行为仍需实机验收。

休憩界面采用深青纸纹、米白文字与朱砂水墨装饰：顶部圆角预告卡片、全屏大倒计时、平滑进度环与缓缓游动的小锦鲤；支持系统高对比模式。Windows截图测试输出 `rest-warning.bmp` 和 `rest-fullscreen.bmp`；游鱼渲染测试输出 `koi-motion-00.bmp` 至 `koi-motion-11.bmp`，用于抽查自然游动帧。

全屏休息采用设计提供的自然游动锦鲤，50 帧、每帧40毫秒循环播放，位置跟随真实休憩进度，一轮休息恰好顺时针绕环一圈，摆尾仍每2秒循环。进度环显示真实休憩进度。动画仅在画面显示期间刷新；系统关闭动画或启用高对比模式时停止摆尾与高频刷新，鱼的位置随每秒计时更新。Esc／×只隐藏画面，“结束休息”提前结束本轮。

召唤页左右分栏随窗口大小伸展，可拖动分隔线调宽，双击恢复默认比例；比例单独保存在 `ui-state.json`。列表与表单独立平滑滚动，保留触控板小增量并遵循系统滚动设置。导航使用六枚水墨图标，操作符号保持独立映射，焦点改为内部描边。

Windows交互验收可设置 `DUNYU_UI_TRANSITION_CHECK=1` 后运行 `cargo test editor_drafts_selection_layout_and_target_state -- --test-threads=1`，连续采集切页过程到 `target/ui-preview/transition-*.bmp` 并检测大面积白块。该检查需暗色主题和可见、无遮挡的真实桌面；当前环境未执行。

分发运行只需 `dunyu.exe`：图标和锦鲤素材已嵌入EXE，无需额外的resources文件夹。运行时在程序旁的 `data` 文件夹保存配置、布局和窗口恢复记录；这是用户数据，请保留。

## 常见问题

### 更新后图标或界面没有变化

程序采用单实例机制，旧版仍驻留托盘时，再次启动会打开旧实例。先从托盘退出，再运行新文件。若只有桌面快捷方式图标未更新，可将新包解压到不同目录直接运行，以区分程序与系统图标缓存问题。

### Win 组合键能录入但无法保存

录入和注册是两个步骤。系统保留或其他程序占用的组合键可能无法注册；请更换组合。保存失败会保留原配置。

### 召唤未匹配到窗口

核对高级选项中的进程路径、类名和标题条件。标题可能包含会变化的文件名；只按程序匹配时可清空标题。使用快捷方式启动时，应填写目标进程的实际 EXE 路径。

滑块残影回归：在可见的 Windows 桌面设置 `DUNYU_UI_OPACITY_CHECK=1`，运行界面集成测试；比较实际拖动与完整重绘的滑块截图，产物为 `opacity-actual.bmp` 和 `opacity-redrawn.bmp`。

## 发布资源体积

运行时使用 `resources/optimized` 中已提交的字体子集和无损图集，普通 Cargo 构建无需 Python。完整字体和设计稿保留为生成输入，不直接内嵌。子集字体名为 DunYu Serif SC，保留 Regular / SemiBold 两种字重、GB2312 字符及源码用字，继续遵循原 OFL 许可；超出字库的动态标签使用系统 UI 字体。

修改界面文案或原始素材后，用 Python 3.11 重新生成并提交资源：

```sh
python -m pip install -r scripts/asset-requirements.txt
python scripts/prepare-assets.py
python scripts/prepare-assets.py --check
```

检查模式不写入资源，并验证字形覆盖、字符宽度、行高和图集像素。CI 检查生成结果是否过期，并在 Windows 构建摘要中记录 EXE / ZIP 字节数。Windows 验收需在未安装原字体的系统上检查两种字重、生僻字规则名，以及 100%、125%、150%、200% 缩放下的字体和图集边缘。

切换卡顿或短暂花屏可使用 [Windows 交互诊断包](UI-DIAGNOSTICS.md)，采集操作耗时、实际逐帧画面及采样缺口。诊断测试默认不运行。


## 传讯

在“传讯”页配置企业微信自建应用的企业 ID、应用 ID、Secret 和接收成员，保存后可点击“发送测试消息”验证已保存的配置。接收成员默认为 `@all`（该应用可见范围内的全部成员）；也可填写成员 UserID，多个成员用 `|` 分隔。需按企业微信后台要求配置应用权限及可信 IP；接口错误会显示在页面状态中。

关键词每行一个，忽略首尾空白、空行和大小写，命中任意关键词即匹配。匹配范围是原始通知 XML，包含元数据和正文，并非严格的应用身份识别。默认关键词为 `telegram`。默认每10秒检查、延迟60秒发送；检查间隔支持1～3600秒，延迟支持0～3600秒。每条通知独立计算延迟，到期后复查原通知行，仍存在才发送标题和正文。通知行消失并不等同于准确判断“已读”。长消息在2048字节内按字符边界截断并标记。

启用传讯前须完成配置并保存。停用时可保存未填写完整的设置；保存失败保留旧配置。修改其他页面不会重启监听。每次启动、重新启用或修改传讯配置都从数据库当前最新ID开始，历史通知不补发。停用或退出丢弃待发通知，已经发出的请求可能完成。网络错误不自动重发；明确凭据失效时刷新凭据后重试一次。页面显示本次监听的待发、成功、跳过、失败计数及最近状态。

企业 ID、应用 ID、Secret、接收成员全部通过当前 Windows 用户的 DPAPI 加密后保存在 `data/config.json`。已保存值不回显，也不提供明文查看按钮；四个输入框使用密码样式，留空保留已有值，填写新值则替换。首次配置接收成员留空时，仍默认发给全部成员。保存成功清空替换输入并折叠已完整配置的企业微信区域；失败时保留遮挡状态的草稿。“清除企业微信配置”立即清除四项并停用传讯。

旧版明文企业 ID、应用 ID 和接收成员在 Windows 启动时自动迁移为密文；已有 Secret 密文保持不变。迁移失败保留原文件并停止传讯，未加密的旧值不能再次写入配置。换电脑或账户后如无法解密，请重新填写四项。凭据、通知正文和访问 token 不写入诊断日志。

企业微信配置完整时默认折叠；未完成时展开。展开后企业 ID、应用 ID、接收成员同行，Secret 单独一行；检查间隔与延迟也并排。关键词框不显示系统滚动条，鼠标指向框内时滚动关键词，指向框外时滚动页面。折叠或切换页签不会丢弃未保存的输入。默认窗口采用一页紧凑布局；较小窗口保留整页滚动。

实际通知读取、系统清除行为及企业微信连通性需在 Windows 10/11 实机验证。数据库不可读时会显示错误并重试，不影响快捷键和休憩。


## 召唤快捷键优先接管

在召唤规则的“高级选项”中勾选“优先接管快捷键”并保存，可用后台键盘钩子接管该规则的组合键，尝试覆盖 Windows 或其他软件的原快捷键，例如 Win+E、Win+R。默认关闭，旧配置仍使用普通快捷键注册。接管只作用于启用的召唤规则，遁鱼内部的重复快捷键仍会拒绝保存。

接管模式按下只触发一次，长按不会反复隐藏／显示。录入快捷键期间暂停接管；修改或保存失败保留原绑定。停用规则或退出遁鱼后恢复原快捷键行为。取消接管时若普通注册仍有冲突，保存会失败，旧接管规则继续生效；可先停用规则或更换组合键。

此功能无法保证覆盖所有系统组合键；Ctrl+Alt+Del、安全桌面、锁屏等不属于普通键盘钩子可保证接管的范围。其他软件的键盘钩子及权限差异也可能影响效果。Win/Alt 组合使用空操作按键屏蔽菜单误弹；若系统拒绝此操作，该次按键放行。程序模拟注入的按键不会触发接管召唤。Windows 实机需验证系统动作不再触发、Win/Alt 松开不误弹菜单、左右修饰键、录入、长按、保存失败与退出后的恢复。
